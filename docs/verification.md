# 验证记录

更新日期：2026-10-25。当前环境是 Windows，Node.js v24.19.0。自动测试不使用真实 API Key、QQ 账号或外部用户，测试数据仅留在被 Git 忽略的 `.cache/tests`。

## 已实现的自动验证

本地 `npm test` 已通过 **15 项测试**，同时通过锁文件 `npm ci --ignore-scripts --dry-run` 检查。测试会先编译 TypeScript，主要覆盖：

- 使用**真实固定版本官方 Harness**启动独立进程，连接本地 Chat Completions SSE 模型端点和本地 OneBot WebSocket。
- 实际对话请求、无工具暴露、显式长期记忆注入、重启续聊、原生手动及自动摘要、新会话、记忆更正/删除和模型切换。
- 会话轮次达到 200 后的原生摘要衔接，模型返回错误后不发送旧回答，恢复后继续聊天。
- 主人一次性配对、过期和替换、拒绝非主人及群聊、入站去重、普通聊天不自动记忆。
- 通知延时、幂等键、队列重启恢复、不带被动回复字段、结果不明不盲目重试、旧主人任务不能改投。
- 直接使用腾讯 SDK 1.0.5 连接本地 HTTP 服务，检查实际主动发送 JSON 中**不存在 `msg_id/event_id`**，被动回复才有 `msg_id`。
- OneBot 认证、群聊与自发消息过滤、文本段发送、断线重连；备用配置仅监听本机，内容日志关闭。
- SQLite 及原生会话一致性备份与恢复，配对、长期记忆、通知保留，不复制环境密钥。
- 72 小时验收逻辑使用虚拟时间验证，必须人工接收确认；虚拟时间验证**不等于**完成真实 72 小时测试。

部署 shell 脚本在本地用 Git Bash 做语法检查。GitHub Actions 已配置 Windows 与 Ubuntu 22.04 构建/测试，以及 Linux shell/systemd 配置检查；尚未在你的 GitHub 仓库触发运行。
